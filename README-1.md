# NexusChat 💬

**A Real-Time Chat Application built with Node.js, Express and Socket.IO.**

NexusChat is a web-based chat application that enables users to communicate in real time. It supports public messaging, private messaging, and live online-user updates through WebSocket communication.

## 🚀 Live Demo

[Open NexusChat](https://pesky-agnostic-creme.ngrok-free.dev)

> Note: This is a temporary demo link. Availability depends on the development server and ngrok tunnel being active.

## ✨ Features

- Real-time messaging
- Public chat functionality
- Private messaging
- Online user updates
- Join and leave notifications
- Interactive chat interface
- Server-client communication using Socket.IO

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Node.js | Runtime environment |
| Express.js | Backend framework |
| Socket.IO | Real-time communication |
| EJS | Server-side templating |
| JavaScript | Application logic |
| HTML & CSS | User interface |

## 📦 Installation

### 1. Clone the repository

```bash
git clone https://github.com/theharshadramayane-ship-IT/NexusChat.git
```

### 2. Open the project folder

```bash
cd NexusChat
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the application

```bash
npm start
```

### 5. Open in your browser

Visit:

```text
http://localhost:3000
```
